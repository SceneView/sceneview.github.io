An ARCore session declared as Compose UI.

ARSceneView is a @Composable that embeds a Filament + ARCore viewport. Its trailing content block is an ARSceneScope DSL where AR-tracked nodes — anchors, augmented images, face meshes, cloud anchors, hit-result cursors — are composable functions that follow the same Compose lifecycle as any other UI element.

Drive AR state with ordinary Compose mutableStateOf: when state changes, the composition updates and the 3D scene reflects it on the next frame.

Minimal usage

var anchor by remember { mutableStateOf<Anchor?>(null) }

ARSceneView(
    modifier = Modifier.fillMaxSize(),
    onSessionUpdated = { _, frame ->
        if (anchor == null) {
            anchor = frame.getUpdatedPlanes()
                .firstOrNull { it.type == Plane.Type.HORIZONTAL_UPWARD_FACING }
                ?.let { frame.createAnchorOrNull(it.centerPose) }
        }
    }
) {
    anchor?.let { a ->
        AnchorNode(anchor = a) {
            ModelNode(
                modelInstance = rememberModelInstance(modelLoader, "models/helmet.glb"),
                scaleToUnits = 0.5f
            )
        }
    }
}

When anchor is set, AnchorNode enters the composition and the model appears in AR. When cleared, both are removed and destroyed automatically — no cleanup code needed.

Parameters

modifier

Modifier for the underlying AR surface.

surfaceType

SurfaceType.Surface (SurfaceView, best GPU performance) or SurfaceType.TextureSurface (TextureView, supports alpha blending).

engine

Shared Filament Engine. Use rememberEngine.

modelLoader

Loader for glTF/GLB models. Use rememberModelLoader.

materialLoader

Loader for Filament material templates. Use rememberMaterialLoader.

environmentLoader

Loader for HDR environments. Use rememberEnvironmentLoader.

sessionFeatures

ARCore Session.Features to enable (e.g. front camera).

playbackDataset

Optional MP4 dataset File previously written via Session.startRecording. When non-null, ARCore replays the dataset instead of using the live camera — the session re-runs as if you were there. Useful for record-replay debugging, deterministic AR tests, and sharing reproducers between developers without needing the original device or location.

sessionCameraConfig

Selects the ARCore CameraConfig for the session. Defaults to highestResolutionCameraConfig, which picks the highest-resolution BACK-facing 30 FPS config the device exposes — so ARRecorder recordings capture at full camera resolution instead of ARCore's low-res 640×480 CPU-stream default (#1065). Pass null to keep ARCore's stock default config.

flashMode

ARCore v1.45+ Flash Mode — drives the device torch during the AR session for low-light tracking (Config.FlashMode.OFF / Config.FlashMode.TORCH). Default OFF. Support-gated — unsupported devices / front-camera configs silently downgrade to OFF (#1732).

sessionConfiguration

Callback to configure the ARCore Session and Config. SceneView pre-sets config.lightEstimationMode = ENVIRONMENTAL_HDR (replacing ARCore's AMBIENT_INTENSITY default) BEFORE invoking this callback, so the IBL baseline shipped by rememberAREnvironment is replaced by ARCore's real-environment estimate once stable. Front-camera sessions still force DISABLED regardless. Override inside this callback to choose a different mode if needed (#1063).

planeRenderer

Whether to render the AR plane grid overlay.

cameraStream

ARCameraStream for camera texture rendering and occlusion.

view

Filament View for this scene. Use rememberARView (default), which is tuned so the live camera background round-trips back to the original camera pixels (see createARView).

isOpaque

Whether the render target is opaque. Default true.

renderer

Filament Renderer. Use rememberRenderer.

scene

Filament SceneView graph. Use rememberScene.

environment

IBL + skybox environment. Use rememberAREnvironment.

mainLightNode

Primary directional light. Use rememberMainLightNode.

fillLightNode

Secondary fill light (softer ambient — opposite-side directional at ~30% main intensity). Mirrors the 3D SceneView v4.1.0 two-light setup so the AR scene baseline matches the 3D demos. Use rememberFillLightNode or pass null for a single-light setup. ARCore light estimation still drives mainLightNode; fillLightNode keeps its baseline color/intensity untouched (#1063).

cameraNode

AR camera node. Use rememberARCameraNode.

cameraExposure

Optional absolute exposure scaling for the AR camera (Filament's single-Float setExposure overload — 1.0 ≈ ISO 100 ≈ EV 0). Not a signed EV-stop bias: negative values clamp to zero (full black, #1179). Realistic range ~0.05 - ~16. Prefer leaving null — the ARDefaultCameraNode default (f/12, 1/200 s, ISO 200 ≈ EV 11.6) is correct for both back- and front-camera sessions after the #1088 + #1067 + #1063 / #1075 realignment.

collisionSystem

Hit-testing and collision system. Use rememberCollisionSystem.

viewNodeWindowManager

Off-screen window manager required for SceneScope.ViewNode.

onSessionCreated

Called once when the ARCore Session is ready.

onSessionResumed

Called each time the session is resumed.

onSessionPaused

Called each time the session is paused.

onSessionFailed

Called if ARCore fails to initialize (missing ARCore or permission).

onSessionUpdated

Called once per AR frame before the scene is updated.

onTrackingFailureChanged

Called when the camera TrackingFailureReason changes.

onGestureListener

Gesture callbacks — tap, double-tap, drag, pinch, etc.

onTouchEvent

Raw touch event callback with optional hit result.

permissionHandler

ARPermissionHandler for camera permission and ARCore install checks. Auto-created from the host ComponentActivity when available. Pass null to skip permission checks.

lifecycle

Lifecycle that binds the AR session resume/pause cycle.

content

Declare AR scene content using the ARSceneScope composable DSL.
