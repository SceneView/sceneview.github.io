CloudAnchorRegistry
Link copied to clipboard
interface CloudAnchorRegistry

Lightweight local store for ARCore Cloud Anchor IDs that an app has hosted (or wants to remember after resolving). The library does not persist anchors itself — Cloud Anchors are server-side state managed by Google's ARCore API — but apps that host long-ttl anchors typically need a small client-side index keyed by a user-meaningful name so the IDs can be passed back to CloudAnchorNode.Companion.resolve on the next launch.
